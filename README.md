## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Game Library** | Organize PS Vita titles with cover art and Vita3K compatibility ratings |
| **Config Profiles** | Save graphics and compatibility settings per game title |
| **Compat Tracker** | Track playable, ingame and menu status per title in your version |
| **Quick Launch** | Launch any title directly with its saved configuration profile |
